## 4. Quality Gates & Validation Protocol

Before any code deployment or architectural modification is committed, execute the local zero-dependency validation suite from project root:

```bash
# 1. Verify Mermaid syntax across all .mmd diagrams
node scripts/validate-mermaid.js

# 2. Verify document structure, links, and frontmatter metadata
node scripts/validate-structure.js

# 3. Perform semantic cross-document traceability check (PRD <-> SRD <-> ERD)
node scripts/validate-output.js

# 4. Execute zero-credential security audit (detect and redact sensitive keys)
node scripts/secret-scan.js --check
```

---

## 5. Security & Zero-Egress Governance

1. **No External Network Dependency**: This documentation generation and validation suite never executes outbound network requests.
2. **Credential Sanitization**: Passwords, API tokens, and private keys are never stored in `./docs/`. Connection strings use placeholder tokens (e.g. `{{SECRET_DATABASE_PASSWORD}}`).
3. **Immutability of Audit Trails**: Changes are recorded append-only in `.architect-audit.log`.
